# ThreeJS Toolpath Render

Effectively trying to copy the toolpath copying of
[this project](https://gcode.vectric.com/). I will be using
[three.js](https://threejs.org/), [React](https://react.dev/) (with
[Typescript](https://www.typescriptlang.org/)). I use
[yarn](https://yarnpkg.com/) as the package manager. To make passing global
state easier, I will use [zustand](https://github.com/pmndrs/zustand/).

## three.js with React

I will use
[this blog post](https://dev.to/omher/how-to-start-using-react-and-threejs-in-a-few-minutes-2h6g)
to get started with using [three.js](https://threejs.org/).

## zustand

I will use
[this blog post](https://dev.to/avt/understanding-zustand-a-beginners-guide-with-typescript-4jjo)
